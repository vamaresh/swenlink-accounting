# SwenBooks Android Wrapper

This is a Trusted Web Activity Android wrapper for:

```text
https://books.swenlink.co.uk/app
```

Package name:

```text
uk.co.swenlink.books
```

The project targets Android API 35 for Google Play submission compatibility.

Release signing and Digital Asset Links must be completed after the Google Play app is created and the Play app signing SHA-256 certificate fingerprint is available.
